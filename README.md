# Skill Shelf for Magpie

简体中文 · [English](README.en.md)

给你的 AI Agent Skills 一个看得见、理得清的书架。在 Magpie 中安装，直接在应用窗口中查看已有 Skills、整理文件夹和标签，再用 Packs 保存自己的常用组合。

不需要另外安装 [Skill Shelf 桌面客户端](https://github.com/voidrinz/skill-shelf)，即可开始使用。

## 你可以用它做什么

- **发现与安装 Skills**：浏览 skills.sh 排行、趋势、热门、官方来源和主题，搜索并查看详情，确认后安装到全局或已添加项目。
- **管理 Agent 接入**：将全局共享 Skills 以软链接或副本接入 Agent，先查看预览，再更新副本、修复链接或断开接入。
- **编辑项目指令**：在项目范围编辑 AGENTS.md、CLAUDE.md，或为 Claude 添加 AGENTS.md 引用。
- **找到已有 Skills**：集中查看不同 Agent 和项目里的 Skills，搜索名称，确认各自安装在哪里。
- **按自己的习惯整理**：创建文件夹、添加标签，在图标、列表和分栏视图之间切换，直接阅读简介和预览文件。
- **建立自己的 Packs**：把常用 Skills 复制成独立收藏，按任务组合，需要时导出或部署。
- **让 AI 帮你理解**：使用 Magpie 中已有的模型，询问某个 Skill 的用途、生成简介或翻译简介。
- **与桌面客户端同步**：通过 WebDAV 或同步文件，交换 Packs 和整理信息。

当前插件版本为 **v0.1.15**，以 Skill Shelf 客户端 **v0.1.14** 为核心功能对齐基线，提供 Skills 整理、市场与安装、Agent 接入、项目指令及独立 Packs。两端使用相同的 v5 同步文件格式；插件版本与客户端基线分别维护，具体差异见 [功能对齐记录](FEATURE_PARITY.md)。

## 开始使用

### 1. 下载插件

先安装 [Magpie](https://usemagpie.ai)。在 GitHub 仓库页面点击 **Code → Download ZIP**，下载并解压；也可以用 Git：

```sh
git clone https://github.com/voidrinz/skill-shelf-magpie-plugin.git
```

仓库已包含构建好的插件。只是使用插件，不需要安装 Node.js，也不需要自己编译。

### 2. 添加到 Magpie

打开 Magpie 的**插件**页面，将解压或克隆得到的 `skill-shelf-magpie-plugin` 文件夹作为本地插件添加，然后启用。请选择包含 `package.json` 的文件夹，不是里面的 `dist` 子目录。

习惯用命令行的话，也可以运行：

```sh
magpie plugin add /absolute/path/to/skill-shelf-magpie-plugin
```

把示例路径替换成插件文件夹的实际位置。安装后请保留这个文件夹，不要随意移动或删除。

### 3. 打开书架

插件默认在后台启动，不会在 Magpie 启动、重启或重新加载插件时自动弹出网页。默认使用 `127.0.0.1:47822`；如果端口已被其他程序占用，会自动选择空闲端口，不需要你修改代码或手动设置。

启用后，在 Magpie 侧边栏的**插件 → Skill Shelf** 中直接打开书架。书架显示在 Magpie 应用窗口内，设置也从书架内进入。需要支持 `magpie.page` 的新版 Magpie；如果侧边栏没有入口，请先更新 Magpie，再关闭并重新启用插件。

插件使用 Magpie 的正式页面入口，本地服务继续负责扫描和文件操作。页面会自动连接实际启动地址，包括端口被占用后的备用地址。插件安装目录需要可写，以便启动时更新应用内连接文件。

Magpie 的页面沙盒不提供浏览器存储和下载权限：应用内偏好保存在书架数据中；导出 Pack 或同步数据时，文件保存到书架数据目录的 `exports/`，随后自动打开该文件夹。外部链接通过系统浏览器打开。

也可以打开插件数据目录里的 **`Skill Shelf.html`**，点击**打开书架**，继续使用独立浏览器。这个本地入口会使用实际地址；自动避让后的端口可能变化，不建议只收藏某个端口地址。

**使用时请保持 Magpie 运行。** 如果不用桌面应用，可以保持 `magpie web` 运行；单次安装命令结束后，不会让工作台一直在线。

### 启动选项（高级）

通常不用修改。插件支持 `open`（启动时自动打开网页，默认 `false`）、`port`（首选端口，默认 `47822`，占用时自动避让）和 `dataDir`（书架数据目录，必须是绝对路径）。只有明确设置 `open: true` 才会自动打开网页。如果旧配置开启了自动打开，可以关闭它，应用内入口不受影响：

```sh
magpie plugin options /absolute/path/to/skill-shelf-magpie-plugin '{"open":false,"port":47822}'
```

将路径替换为安装插件时使用的本地目录；其他安装方式使用对应的安装标识。选项在插件宿主重新加载时应用。改变 `dataDir` 会使用另一份书架数据，不会自动迁移原数据。

Magpie 目前只给网关中间件显示图形化的**选项**按钮；Skill Shelf 不处理网关请求，因此不会为了这个按钮注册空中间件。扫描来源、外观、AI 和同步等业务设置仍在**书架设置**中管理，不需要编辑启动选项。

## 第一次打开，先做这几件事

1. 在**工作台**查看发现了哪些 Agent 和 Skills。
2. 进入 **Skills**，选择范围、搜索或切换视图。如果少了某个目录或项目，在**设置 → Skills 与 Agent** 中添加，再点击**重新扫描**刷新本地列表。
3. 打开一个 Skill，阅读简介和文件，再给它添加文件夹和标签，方便下次找到。
4. 右键点击 Skill，选择**导入到 Packs**，保存一份独立副本到 Default Pack，再到 **Packs** 中整理。

需要新 Skill 时进入**发现**，或在 Skills 页点击**从来源安装**。支持 GitHub 仓库、skills.sh 链接、绝对路径本地来源，以及可识别的 `npx skills add` 命令文本；插件不会执行任意粘贴命令。安装先在隔离目录下载，再验证并写入目标，同名安装不会静默覆盖。安装、更新和移除都需要明确确认。

在**工作台 → 管理接入**查看共享 Skills 的接入状态。直读共享目录的 Agent 无需额外部署；已有外部文件不会被自动接管、覆盖或删除，修改过的托管副本也受到保护。预览过期或文件变化时需重新预览。共享目录接入与 Pack 部署分别管理。

进入项目范围后，点击**项目指令**即可编辑。已有文件保存前会备份，并检查它是否被其他编辑器修改；软链接等不可安全编辑的文件会显示为只读。

对于支持检查更新的已安装 Skills，可以点击**扫描更新**，查看结果后再确认更新。与整理和预览不同，更新会改动对应的安装文件。

## Packs 怎么用

Pack 就是你自己的 Skill 组合，比如「写作」「前端开发」或「代码审查」。导入时会复制一份，原来的 Skill 不会被移动或修改。

你可以把 Pack 导出成客户端兼容的 v5 文件，用来分享或备份；导入时先检查预览和冲突，仍支持旧版插件的 Pack 文件，也可以把其中的 Skills 部署到某个 Agent 的 Skills 文件夹。**文件复制**会生成独立文件；**软链接**则让目标位置继续引用 Pack 中的文件。使用软链接时，删除源文件前需要先移除对应部署。删除 Pack 不会删除之前部署出去的文件副本。

## AI 可以帮什么忙

在工作台设置中选择模型和输出语言，然后使用 AI 助手或 Skill 简介相关操作。插件直接使用 Magpie 中已有的模型，不需要在这里重新注册供应商或填写 API Key。普通文件预览不会调用 AI，目前也不提供整个文件的翻译。

AI 只在你主动请求时调用。相关 Skill 文本、你的问题和对话上下文可能发送给 Magpie 中配置的模型供应商，费用、额度和隐私规则仍以该供应商为准。不使用 AI，也可以正常浏览和整理。

## 与桌面客户端同步

同步是可选的，需要手动操作，不会实时自动同步：

1. 在插件的**设置 → 同步**和 Skill Shelf 桌面客户端中，填写同一个 WebDAV 地址与账号。
2. 在有数据的一端上传，查看预览和冲突后确认。
3. 在另一端拉取，检查预览后确认合并。

不用 WebDAV，也可以在**同步**中导出文件，再到另一端导入。与桌面客户端交换整套整理信息时，请用这里的同步导出，不是单个 Pack 的导出。

同步包含 Packs 的文件副本，以及能匹配上的已安装 Skills 的文件夹、标签、排列位置、自定义描述、简介译文和文件夹视图设置。主题、密度、关注 Agent 等可迁移偏好也按字段合并；Magpie 的模型账号与密钥不由插件接管。**它不会把原始已安装 Skills 自动安装到另一台机器**，需要先在那台机器上安装。插件的同步与 Magpie 自身的同步相互独立。

请使用可信的 WebDAV 服务：桌面客户端的同步文件可能含有 AI 凭证。插件也会在本机保存 WebDAV 密码，但不是加密存储。

## 常见问题

### 整理会修改我原来的 Skills 吗？

不会。文件夹、标签、文件预览和 AI 注释都不改动原始 Skill 文件。只有你确认的安装、更新、移除、Agent 接入、项目指令保存和 Pack 部署会写入文件，请在操作前检查目标。插件不会执行 Skill 里的脚本。

### 工作台打不开怎么办？

确认 Magpie 正在运行，插件已启用。如果插件还没加载，先打开一次 Magpie 的插件页面。重启或更新插件后重新打开侧边栏的 Skill Shelf；如果仍显示旧版本，先关闭再重新启用插件。

### 默认端口被占用了怎么办？

会自动避让。插件不会关闭占用端口的程序，也不会误用另一个书架的数据；同一份书架被多个 Magpie 进程加载时，会复用同一个工作台。重启时会尝试沿用上次地址；如果它也被占用，就重新选择空闲端口，并更新手动打开入口，默认不会弹出网页。

这个功能不依赖 Magpie 的图形端口设置，也不需要修改源码、JSON 或运行命令。找不到当前地址时，重新打开 `Skill Shelf.html` 即可。

### 还需要从添加供应商里打开吗？

不需要。插件已改用 Magpie 的 `magpie.page` 页面入口，不再注册供应商或登录按钮。更新后请关闭并重新启用插件，从侧边栏的**插件 → Skill Shelf** 进入。

### 数据保存在哪里？

书架数据保存在本机 Magpie 配置目录下的 `skill-shelf/` 文件夹中，`Skill Shelf.html` 入口也在这里。默认路径通常是用户主目录下的 `.config/magpie/skill-shelf/`；如果你自定义过 Magpie 配置目录，则以实际目录为准。在 macOS 的 Finder 中，可以用**前往 → 前往文件夹**输入 `~/.config/magpie/skill-shelf/`，再双击入口文件。

关闭书架页面或移除插件不会自动删除这些数据。手动清理前，请先备份重要 Packs。
